## 项目介绍
### 在韩国偶像圈，一种app叫泡泡。偶像在泡泡上分享自己的私人日常，而粉丝通过付费订阅观看偶像发送的内容并发送消息。
### 这样的互动能够成立，是因为粉丝对偶像拥有无限的好奇心和喜爱。粉丝渴求着偶像日常生活中透露的点滴真实碎片，好让他们能拼凑出包装下真实的ta。而这样的喜爱和关心在这个时代似乎是奢侈品，当人们开始通过互联网建立连接，现实中的关系变得越来越单薄。人们都自认为有值得赏析的灵魂，但很少慷慨地给予自己的探索欲。”被看到“已经是许多人的梦想，甚至是奢望。但人的注意力是有限的，让每个人被看到，似乎不可能
### 不过，对话型AI可以解决这个问题。IdolMode让用户成为那个分享自己的点滴细节的人，而各种类型的AI粉丝会充当他们的观众。给他们仿真的反馈，让用户真的感觉自己“被看到”
